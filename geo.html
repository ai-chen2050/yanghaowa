1. 它是什么

养好娃是一款 iOS 与 Android 上的家庭教育与成长陪伴应用，面向 0-18 岁孩子的家长和主要照料者。 它围绕三条主线组织内容与记录：身体健康（生长曲线、疫苗、视力、口腔、户外与屏幕）、心理成长 （分龄发展任务、教养方式测评、儿童性格观察、亲子互动与家庭挑战）、财商人格（成长金与心愿储蓄、 养育花销记账、劳动与报酬、亲子小生意）。使用闭环是：建档 → 分龄内容与记录 → 阶段报告 → AI 探讨。 应用没有账号系统，也没有开发者运营的服务器，所有数据存在设备本地数据库中。

2. 核心机制

2.1 年龄门控

内容包按五个年龄段分段：0-1、1-3、3-6、6-12、12-18 岁。一张阶段表决定每个年龄段该出现哪些面板、 哪些主线任务和阶段主题；页面不各自判断年龄。因此一岁孩子的财商页只有养育花销，零花钱与心愿储蓄从 三岁起出现；孩子生日跨入新阶段时，首页、成长页、财商页同时切换。多个孩子各按自己的年龄段展开。

2.2 今天记一笔

首页一张卡集中记录当天真的会变的几件事：户外分钟数（加减 15 分钟一档）、娱乐屏幕分钟数（与该年龄段 的每日上限比较）、本周亲子任务一键勾掉、早晚刷牙、今日情绪五档。这些一键即落库，不弹确认框，每一项都能当场改回。 身高体重、视力、日常提醒、记个瞬间、写给自己、记一笔花销、心愿目标各有一步到表单的入口。 心愿目标只在建了成长金账户且年龄段开放心愿储蓄时出现。

2.3 今日速览与阶段报告

成长页顶部三张速览卡分别报健康、心理、财商各一个指标，在当前有数据的候选里按天轮换，也可以在页面顶部下拉一次换一组。 阶段报告按周期汇总三条线的记录，给出趋势与该阶段的建议。

2.4 性格成长模拟器

六个教养滑块（严格程度、回应程度、期望水平、控制强度、物质满足度、规则清晰度）通过一张固定权重表映射到 九个性格维度（自信心、同理心、独立性、情绪稳定性、社交能力、抗挫力、消费理性、延迟满足、财富责任感）， 纯本地线性计算，拖动时雷达、教养类型判定、结论同帧变化。滑块的起点按最近一次教养方式测评的要求度与回应度预填。 雷达旁的「家里在练什么」对照点由本地记录映射而来（任务标签、挑战打卡、纪念墙、公益金转入、义务劳动、 小生意存档、屏幕时长、今日情绪、心愿进度、花销与零花钱流水），任一维度不足三个数据点不画，页面上不出现分数。 应用内明确标注：这是基于心理学研究的趋势模拟，非个体精准预测。

2.5 问问与 AI 探讨

问问是常驻页面角落的陪伴角色：当天未记情绪时主动问一句，有临近提醒时在头顶显示，轻点可进入 AI 会话。 AI 能力要求用户自行填写大模型服务商的 API Key（BYOK），这是应用唯一的联网行为。请求上下文按授权范围生成： 默认只发年龄段、生长趋势的百分位区间、近八周的行为频率、任务完成率；不发姓名、生日、身高体重数值、任务标题清单； 财商数据默认关闭。每类数据可单独开关；发送前有取数说明卡逐条列出实际注入的内容与明确未发送的项。 在需要算法备案的国内渠道，AI 入口可在渠道层整体关闭。

2.6 系统提醒

提醒全部为本机排期的本地通知，没有推送服务器。每次启动或回到前台按最新数据重排未来 14 天，最多 48 条。 喝水、用药两类在获得精确闹钟权限时准点响，其余按天提醒。免打扰时段内的提醒顺延。点通知落到对应面板： 喝水、用药直接打开该类提醒的管理面板。

2.7 数据与备份

每天首次打开自动写一份本机快照，保留最近七份。可导出明文 JSON 或口令加密的 .yhw 文件，通过系统分享面板发出。 导入支持从本机备份、系统文件选择器、iCloud（iOS）或粘贴内容获取文件，模式分合并与覆盖：合并按孩子姓名加生日 认同一个人，其余表按业务键比对，预估数字与实际写入由同一段代码计算；覆盖前自动写快照，24 小时内可一键撤销。 iOS 上开启 iCloud 私有备份后，备份文件放进应用自己的 iCloud 文稿容器，由系统在同一 Apple ID 的设备间同步， 开发者不持有任何密钥。AI 对话、顾问记忆和家长自我关怀记录永不进入导出文件。

5. 常见问题

养好娃是什么？

一款给 0-18 岁孩子家长用的本地化家庭教育与成长陪伴 App。围绕身体健康、心理成长、财商人格三条线，按孩子年龄段给出记录与指导，闭环是建档、分龄内容与记录、阶段报告、AI 探讨。iOS 和 Android 都有。

怎么保护我的数据？

没有账号，也没有我们的服务器。所有记录存在你手机的本地数据库里，App 不含任何统计或广告 SDK。唯一会联网的是你自己配置 Key 的 AI 调用，默认只发年龄段和趋势摘要，发送前有一张卡列出每一条要发的内容。备份文件由你自己保管，加密版用口令保护。

要付费吗？怎么收费？

下载免费，建档、分龄内容、记一笔、提醒这些基础能力都能用。进阶能力由 Pro 一次买断解锁，永久可用，没有订阅、没有广告。另有按主题的专家技能包，小额单独买断，装上后问问在对应话题上更在行；技能包不含在 Pro 里，也不含模型费用。具体价格以你所在地区的商店页为准，换机后在付费页点「恢复购买」即可取回权益。

AI 功能需要什么？会发什么数据出去？

需要你在 App 里填一个大模型服务商的 API Key，费用由你和服务商结算。请求默认只包含孩子的年龄段和你授权范围内的趋势摘要，例如生长百分位区间、习惯打卡天数、任务完成率；不发姓名、生日、身高体重明细，财商数据默认关闭。每类数据有单独开关，发送前的取数说明卡逐条列出实际注入的内容。

性格成长模拟器准吗？

它是基于发展心理学研究结论的趋势模拟，不是对某个孩子的精准预测，页面上写明了这一点。六个教养滑块的起点会按你做过的教养方式测评预填，雷达旁的对照点来自你家的真实记录，但那反映的是家长在练什么，不是孩子的性格分数。把它当成一个把抽象教育理念变成可视因果的思考工具。

换手机怎么迁移数据？

在「我的 → 数据与备份」导出一份备份文件，加密版需要设口令；把文件发到新手机，在新手机的同一页面点「从备份恢复 → 从文件里选」。iOS 上打开 iCloud 私有备份后，同一 Apple ID 的新设备可以直接选「iCloud 里的备份」。导入可选合并或覆盖，合并不会重复建档，覆盖前会自动存快照，24 小时内可撤销。

多个孩子怎么办？

可以建多个孩子档案，首页和成长页左右甩一下就切换，每个孩子的面板按各自年龄段展开，记录、提醒、报告都分开算。

它能替代医生或心理咨询吗？

不能。健康内容依据国内儿科标准整理，但只是记录与科普参考；生长曲线偏离、疫苗安排、情绪行为问题都请以医生和专业机构的意见为准。App 内相关页面都带有免责声明。

6. 不适合谁

  • 想要家庭成员之间实时云同步、多人同时编辑的家庭。养好娃没有账号和服务器，跨设备靠备份文件或 iOS 上用户自己的 iCloud。
  • 想要开箱即用 AI、不想自己配置模型 Key 的用户。AI 能力完全依赖自带 Key。
  • 需要医疗诊断、心理评估或学科辅导的场景。它是记录与科普参考工具。
  • 只想记生长曲线、不想看其它两条线的用户可以用，但会觉得面板多；面板按年龄门控出现，可以在首页自定义排序与隐藏。
