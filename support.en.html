Frequently asked questions

I paid but nothing unlocked

Tap "Restore purchases" on the in-app purchase page first. If it says no record was found, make sure you are signed in with the account you bought with (Apple ID for the App Store, Google account for Google Play, Huawei ID for AppGallery). If it still fails, send the order number to the email above. Pro is a one-time purchase, valid for life under the same store account, and you will not be charged twice.

New phone: how do I move my data?

Old phone: "Me → Data & backup → Export", choose an encrypted backup and set a passphrase, then send the .yhw file to the new phone (messaging, AirDrop or cloud drive all work). New phone: install the app, open the same page, tap "Restore from backup → Choose a file", pick that file, enter the passphrase and choose "Merge" or "Replace". iOS users with iCloud private backup turned on can sign the new iPhone into the same Apple ID and pick "Backup in iCloud" directly.

I lost my data

On the first launch of each day the app saves a snapshot on the device and keeps the latest seven; it also saves one before any import or wipe. Go to "Me → Data & backup → Restore from backup" and pick one of those files by date. For 24 hours after an import or wipe an "Undo" bar sits at the top of that page; one tap takes you back to before the action. Uninstalling the app deletes on-device data too, so export a backup before uninstalling.

AI does not work / says it is not configured

AI needs your own large-language-model API key. Go to "Me → AI settings", enter the provider endpoint, model name and key, and send a test message. The key is stored in the system's secure storage and used only for requests you start. The Huawei AppGallery build has no AI entry at all; that is a channel compliance requirement, not a fault.

A reminder did not fire

Check in order: the master switch under "Me → Reminders"; whether system settings allow notifications for this app; and for on-the-minute reminders such as water and medicine, whether the "Exact reminders" row shows as allowed. "Send two test notifications" under "Reminder diagnostics" at the bottom of that page tells you at once whether it is a permission or a scheduling problem. On Xiaomi and similar phones you also need to allow the app to auto-start in system settings, otherwise alarms cannot wake the app after it is cleared from the background.

How do I report a bug or request a feature?

Email us with: device model, OS version, app version and build number (shown under "Me → About"), and the steps to reproduce. Screenshots help. The build number looks like "0906.1234" and tells us exactly which build you have.
